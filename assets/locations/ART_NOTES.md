# World location artwork

Generated with the built-in image_gen tool on 2026-10-31.

Eight world overview panoramas remain available for world cards and menus.

Every playable location now has its own original full painting in `world_N/location_XX.png`: 56 dedicated illustrations across all eight worlds. The choice/input pair of one skill shares that location; different locations never reuse a crop or image. `unique_locations.json` contains the exact prompts, world concepts, names and final project paths.

New division world portraits use square sky crops of the overview panorama. SpaceScene uses the selected dedicated painting and preserves its aspect ratio.
